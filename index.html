Developer Salary Bucket Predictor & Skill Recommender

An interactive client-facing dashboard built on an ordinal logistic regression model trained on the 2026 Stack Overflow Annual Developer Survey. Answer the survey questions behind the model's 658 selected features and it will plot your predicted probability across the 15 ordered salary buckets, then rank the top 3 skills/tools to learn by predicted salary-bucket gain.

How this works

The form below only asks the original survey questions that back the features selected into the final model — never encoded or engineered values. When you click Predict, your answers are converted into the same one-hot feature layout the model was trained on, the training-fitted scaler is applied (no refitting on your answers), and the trained ordinal logistic regression runs entirely in your browser.

Leave anything blank/"Not answered" — the model treats it the same way it treated skipped answers in the original survey.

This is a model-predicted association, not a causal estimate — it does not establish that learning a skill will cause a salary increase (confounders like seniority, country, and company size are not held constant beyond what the model already encodes).

Methods

StepApproach
TargetConvertedCompYearlyBucket (15 ordered buckets)
Feature selectionUnion of above-mean mutual information and above-mean random-forest importance (658 of 1,132 one-hot/engineered features)
Engineered featuresTechStackCount, PreCareerCoding, SeniorManager
ModelCumulative-threshold ordinal logistic regression: 14 binary logistic models (one per threshold), implemented from scratch on sklearn.linear_model.LogisticRegression
TuningGrid search over C & penalty → best: C=0.1, L1 (mean CV MAE 1.492 buckets)
Test performanceAccuracy 0.299, MAE 1.424 buckets (train: 0.394 / 1.301 — some overfitting, expected with 658 features relative to ~9k training rows)

Data privacy

This page ships only the trained model's aggregated parameters (which one-hot options survived feature selection, their coefficients, and the training-fitted scaler's mean/scale) — no individual survey responses are published or transmitted anywhere. Everything you enter in the form above stays in your browser; the prediction runs client-side in JavaScript and nothing is sent to a server.

Glossary

Salary bucket
One of 15 ordered annual-compensation ranges the original survey grouped respondents into, from "$0–<$10,000" to ">$500,000".
Ordinal logistic regression
A classifier for ordered categories. Here it's built from 14 binary models, each asking "is your bucket above threshold k?" — the differences between consecutive thresholds give the probability of landing in each bucket.
Expected bucket
A single summary number for a probability distribution: each bucket index weighted by its predicted probability and summed. Used to rank recommendations.
L1 regularization
A penalty that pushes unhelpful feature weights all the way to zero, so the model effectively selects a sparser, more robust subset of the 658 features.
MAE (buckets)
Mean absolute error between the predicted and true bucket index — "1.4 buckets" means predictions are off by about 1.4 salary ranges on average.
